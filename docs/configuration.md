# Configuration

## `.env` (bootstrap)

Created by `make env` from `.env.example`. **Never commit it.**

| Variable | Default | Notes |
|----------|---------|--------|
| `DOCKER_NAME` | `iapp-skeleton` | Container name |
| `DOCKER_PORT` | `8092` | Published HTTP port |
| `TZ` | `UTC` | Container timezone |
| `NODE_ENV` | `production` | `production` refuses to start without `JWT_SECRET` |
| `PORT` | `3001` | Express inside the container |
| `FRONTEND_URL` | `http://localhost:8092` | CORS + Secure cookie when `https://` |
| `COOKIE_SECURE` | unset | Set `true` if TLS is terminated in front and URL is still `http://` internally |
| `POSTGRES_HOST` | `postgres-18` | Hostname **from the container** |
| `POSTGRES_PORT` | `5432` | |
| `POSTGRES_DB` | `iapp_skeleton` | Underscores: PostgreSQL rejects hyphens in unquoted names |
| `POSTGRES_USER` | `iapp_skeleton` |
| `POSTGRES_PASSWORD` | empty | Wizard can write this (quoted if needed) |
| `DATABASE_URL` | unset | Overrides discrete `POSTGRES_*` until the wizard comments it out |
| `JWT_SECRET` | generated by `make env` | Session HMAC |
| `SETUP_TOKEN` | unset | Optional wizard lock |
| `SETUP_LOCKED` | written by the app | Set to `true` once setup finishes; keeps `/api/setup` closed even during a DB outage |
| `SEED_LOCALE` | first user's language | Language for default groups created on upgrade (`en` / `ru`) |
| `TRUST_PROXY_HOPS` | `1` | Proxies in front of Express (bundled nginx = 1). Behind Traefik / NPM / Cloudflare use `2` |
| `PUBLIC_URL` | `FRONTEND_URL` | Public origin for links in emails/push, the Google redirect URI and link previews (`og:url`, `og:image`; without it the request host is used) |
| `FRONTEND_DIST` | `../frontend/dist` | Built frontend whose `index.html` the app serves with link-preview tags ([link-previews.md](link-previews.md)) |
| `ENCRYPTION_KEY` | derived from `JWT_SECRET` | Key for sealed secrets (Google tokens, VAPID private key) |
| `DISABLE_SCHEDULER` | `false` | `true` stops background jobs (reminders) on this instance |
| `PUSH_CONTACT` | — | Contact email for VAPID when `PUBLIC_URL` is not HTTPS |
| `UPLOAD_DIR` | `/app/uploads` | Avatars, logos, [Files](files.md) blobs (`files/`, legacy Knowledge Base files in `kb/`) and Office previews (`.previews/`) |
| `VITE_API_URL` | `http://localhost:3021` | Dev compose only |
| `WAZZUP_API_URL` | `https://api.wazzup24.com/v3` | Override for tests or an egress proxy |

## Database settings (`app_settings`)

Edited in **Admin → Settings**. Reads are cached for 5 seconds and the cache is dropped on every write. The API rate-limit cap applies immediately; its window applies after a restart.

| Key | Meaning |
|-----|---------|
| `app_name` / `app_description` | Branding |
| `access_mode` | `open` / `closed` |
| `default_locale` | `auto` (browser), `ru` or `en`: language for guests and people who have not chosen one; also used for their emails and notifications. Set from the installer's language at setup |
| `users_locale_cleared` | One-time marker: the old implicit `en` of every user became "as the portal" |
| `default_locale` | `auto` (browser), `ru` or `en`: language for guests and people who have not chosen one; also used for their emails and notifications. Set from the installer's language at setup |
| `users_locale_cleared` | One-time marker: the old implicit `en` of every user became "as the portal" |
| `home_page` | `landing` or a module id (`dashboard`, `files`, `kb`, …): what `/` shows |
| `appearance` | Template, custom colors, default theme, typography, icons, `logoUrl`, `logoDarkUrl`, `logoHeight` (20–64 px), `appIconUrl` (PWA icon), `shortName` (name under the icon) |
| `integrations` | Email, Telegram, WhatsApp Gateway, Wazzup, Mattermost, document conversion, AD (secrets masked in API). Groups added in newer versions are merged in from defaults automatically |
| `security` | Allow/block lists, lockout, session length |
| `auth` | Sign-in methods: `password`, `ldap` (+ `autoProvision`, `groupMap`), `telegram` (+ `autoProvision`), `emailCode`, `whatsappCode`, `telegramCode`, `magicLink` |
| `modules` | `{ <id>: { enabled, settings } }` per module — see [modules.md](modules.md) and [knowledge-base.md](knowledge-base.md#module-settings-admin--settings--modules--knowledge-base) |
| `webpush` | VAPID keys (private key sealed), generated on first use |
| `rbac_seeded`, `kb_seeded` | One-time starter content markers |
| `kb_files_migrated` | Knowledge Base files were moved into the Files module (one-time) |
| `rate_limit_window_ms`, `rate_limit_max`, `rate_limit_user_max` | General `/api` limiter: window (15 min), guests per IP (300), signed-in people per account (5000) — an office behind one NAT address never shares a budget. Not counted: sign-in routes (they have their own brute-force limiters), page-load reads (`/settings`, `/setup/status`, `/apps`, `/notifications/unread`) and file/preview/thumbnail streams |

Security JSON is sanitized on write: lockout 5–180 minutes, attempts 3–30, session 1–90 days. Omitted flags keep their stored value. The rate limit is clamped to 20–100 000 requests and a 1–1440 minute window.

## Frontend

- Locale: `en` / `ru` (user profile + header).
- Theme: light / dark / system (user) plus project default in appearance. *System* follows OS changes live.
- Logo: the primary logo is used everywhere; `logoDarkUrl` replaces it in the dark theme when set.
- Version: root `VERSION` file, synced by `make bump-*`.
